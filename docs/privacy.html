이 도구는 한국이장님 채널 운영자가 자기 계정(@hanguk_ijang)에 직접 만든 영상을 올리기 위해서만 씁니다.

  • 수집하는 정보: 틱톡 로그인 시 받는 접근 토큰과 계정 기본 정보(아이디, 이름). 다른 사용자의 정보는 받지 않습니다.
  • 쓰는 곳: 운영자 본인 계정에 영상을 올리는 데만 씁니다. 판매하거나 다른 곳에 넘기지 않습니다.
  • 보관: 토큰은 암호화된 저장소(GitHub Actions secrets)에만 보관하고, 연결을 끊으면 지웁니다.
  • 문의: walkerwalker9711 (GitHub)

This tool is used only by the channel owner to upload their own videos to their own TikTok account (@hanguk_ijang).

It stores only the OAuth tokens and basic profile of that account, in encrypted GitHub Actions secrets, uses them only

to upload the owner's videos, and never sells or shares them. Revoking access deletes them.
